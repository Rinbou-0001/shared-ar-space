# X UI Study

X（旧Twitter）のデスクトップ画面を参考にした、学習用の静的フロントエンド模造インターフェースです。X公式のソースコードや内部APIは使用していません。

## 起動
`index.html` をブラウザで開いてください。必要に応じてプロジェクトフォルダで `python3 -m http.server 8000` を実行し、`http://localhost:8000` にアクセスします。

## 構成
- `index.html`: タイムライン画面のDOM構造
- `css/style.css`: 3カラムレイアウト、ポスト、レスポンシブ対応
- `js/app.js`: サンプルデータ、投稿、いいね、リポスト、検索、タブ切り替え

## 実装している操作
- テキスト投稿（ページ内のローカル状態に追加）
- いいね / いいね解除
- リポスト / 解除
- おすすめ / フォロー中タブ
- タイムライン内検索
- おすすめユーザーのフォロー状態切り替え
- モバイル幅でのレイアウト変更

## 注意
投稿内容はブラウザ内の一時的な表示だけで、サーバーには保存されません。実際のXアカウント、投稿、DM、通知、認証、APIとは接続していません。画像・動画添付もデモ用です。
