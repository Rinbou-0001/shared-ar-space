# YouTube UI Study

YouTubeのデスクトップUIを参考にした、学習用の静的フロントエンド模造サイトです。YouTube公式のソースコードや内部APIを使用したものではありません。

## 起動方法
1. ZIPを展開します。
2. `index.html` をブラウザで開きます。
3. 動画カードをクリックすると `watch.html` に移動します。

ローカルサーバーを使う場合は、プロジェクトフォルダで `python3 -m http.server 8000` を実行し、`http://localhost:8000` を開いてください。

## 構成
- `index.html`: ホーム画面
- `watch.html`: 動画視聴画面
- `css/common.css`: 共通レイアウトとレスポンシブスタイル
- `js/app.js`: サンプル動画データ、カード生成、検索、カテゴリ絞り込み、画面遷移

## 学習ポイント
- ヘッダー、サイドバー、メイン領域のレイアウト
- 動画カードをデータから生成する方法
- URLクエリ `?v=番号` による動画ページの表示切り替え
- CSS Grid / Flexbox / Media Query
- UIコンポーネントとデータの分離

## 注意
サムネイルはCSSで生成したダミー画像、再生画面はプレイヤー風の静的デモです。実際のYouTube動画の再生、ログイン、コメント送信、YouTube APIとの通信は行いません。ブランド表示も学習目的の簡易表現です。
